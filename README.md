# 생산직 공채 서류검증

API와 인터넷 연결 없이 학교생활기록부 PDF 첫 페이지의 출결표를 읽어 Excel로 정리하는 Windows GUI 프로그램입니다.

## 사용 흐름

1. `서류검증.exe` 실행
2. `PDF 파일 선택`에서 최대 1,000건 선택
3. `서류 검증 시작` 후 저장 폴더 선택
4. 생성된 `서류검증결과_날짜시간.xlsx`에서 `확인필요` 행 점검

원본 PDF는 읽기만 하며 수정하지 않습니다. 개인정보는 외부 서버로 전송하지 않습니다.

## 비개발자 유지보수

GUI의 `설정`에서 다음 값을 바꿀 수 있습니다.

- 지원자번호 파일명 형식(정규식)
- Excel 결과 파일명
- 전 항목이 0일 때 표시할 문구(기본값: `3년개근`)
- 12개 출결 출력 항목명(예: `무단` 또는 `미인정`)
- 숫자가 1건 이상인 지원자를 확인필요로 표시할지 여부
- 검증용 출결표 이미지 저장 여부

설정은 실행 폴더의 `config.json`에 저장됩니다. 설정 화면의 `기본값 복원` 후 저장하면 초기 상태로 되돌릴 수 있습니다. `config.json`을 삭제해도 다음 실행 시 기본값으로 시작합니다.

## 유지보수 경계

- 항목명·파일명·검증 기준 변경: GUI에서 처리
- 교육청 생활기록부 표의 위치나 열 개수가 크게 변경: 추출 엔진 업데이트 필요
- 양식 미인식 파일: Excel에 `확인필요`로 표시되며, 저장된 출결표 진단 이미지를 함께 확인

## Windows EXE 빌드

빌드 PC에만 Python이 필요합니다. 실행 PC에는 Python이 필요하지 않습니다.

1. 이 폴더 안에 Windows용 Tesseract를 `tesseract\tesseract.exe` 형태로 배치하고 `tessdata\eng.traineddata`를 포함합니다.
2. `build_windows.bat`를 실행합니다.
3. `dist\서류검증.exe` 단일 파일을 배포합니다.

단일 EXE는 실행 시 포함된 OCR 엔진을 임시 폴더에 풀기 때문에 폴더형보다 최초 실행이 느릴 수 있습니다.

사내 PC에서는 미서명 EXE가 보안 솔루션에 차단될 수 있으므로 정보보안 담당 부서의 반입·허용 절차를 먼저 확인하는 것이 안전합니다.
