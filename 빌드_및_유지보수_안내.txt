[현재 검증 상태]
- 제공된 PDF 샘플 4건 자동 테스트 통과
- 지원자번호 4건 추출 성공
- 출결 합계: 3건 전 항목 0, 1건 질병조퇴 1 판독 성공

[EXE 만드는 방법]
1. Windows 빌드 PC에 Python 3.12와 Windows용 Tesseract를 설치합니다.
2. Tesseract 설치 폴더 전체를 이 폴더의 tesseract 폴더로 복사합니다.
   예: tesseract\tesseract.exe, tesseract\tessdata\eng.traineddata
3. build_windows.bat를 더블클릭합니다.
4. dist\서류검증.exe 단일 파일이 배포본입니다.

GitHub를 사용할 수 있으면 Actions의 'Build Windows EXE'를 수동 실행해
로컬 Python 설치 없이 Windows 배포본을 만들 수도 있습니다.

[일상 유지보수]
- 프로그램의 '설정' 버튼에서 지원자번호 형식, 결과 파일명, 3년개근 표시문구, 출결 항목명,
  확인필요 기준, 진단 이미지 저장 여부를 바꿀 수 있습니다.
- 설정은 config.json에 저장됩니다.
- 문제가 생기면 '기본값 복원'을 누르거나 config.json을 삭제합니다.

[양식 변경 시]
- 생활기록부 출결표가 12개 항목 구조를 유지하면 대체로 그대로 처리됩니다.
- 열 개수 또는 표 자체가 변경된 PDF는 '확인필요'로 분류됩니다.
- 결과 폴더의 확인용 출결표 이미지와 상세내용을 개발 담당자에게 전달하면
  개인정보 전체 PDF를 전달하지 않고도 추출 로직을 점검하기 쉽습니다.

[보안]
- 프로그램은 PDF를 외부로 전송하지 않으며 API와 인터넷을 사용하지 않습니다.
- 원본 PDF는 수정하지 않습니다.
- 결과 Excel과 진단 이미지에도 개인정보가 포함될 수 있으므로 사내 기준에 따라 보관·삭제합니다.
